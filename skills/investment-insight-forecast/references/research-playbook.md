# 公司研究、推理和图册的整体操作经验

用于需要搭建/复用整体研究方法或交接分析经验的任务。具体来源核验、参考故事、内容融合及视觉实现分别按SKILL路由读取；本参考不携带任何公司的数字、授权、结论或签署。

## 研究链与全景

目标链：问题→当前证据→可比计算→变化/分化→机制及反方→条件未来→可观察复盘。证据整理是基础，不是研究结论；不因因果未完全识别拒绝有证据的优先解释，也不编造未观察事实来让故事完整。

全景同时覆盖客户价值、价值创造、交付责任、收入利润、资本现金、竞争替代和未来风险。财务“收入—利润—资本—现金”检查完整性，商业“创造—交付—获取”解释钱如何流动。多合同按实际问题递进，专题承接跨合同机制；研究扩展、合同验收及正式签署各自记录。

## 最有用的分析动作

| 动作 | 用途与实施 | 限制 |
| --- | --- | --- |
| 找方向分化 | 量/ASP/收入，毛利/费用，利润/现金，产能/产出/销售，总渠道/子路径 | 先算差别，不能由不同步直接确认原因 |
| 拆结构与范围 | 产品、渠道、地区；主营/公司/合并金融；净利/归母 | 分母、期间与范围必须匹配 |
| 精确贡献 | R=Q×P；中点分解ΔQ×均值P+ΔP×均值Q | ASP是组合平均实现收入，非纯提价 |
| 结构毛利分解 | G=Σwᵢgᵢ；中点拆权重与内部率 | 只有类别完备、同范围才可勾稽；不称净贡献 |
| 库存/利润桥 | 先列入出库与调整或损益项目，核残差 | 不拿不同物料造恒等式；剩余不命名为单一原因 |
| 现金覆盖 | CFO−购建长期资产现金 | 是算术代理，不直接等于实体FCFF；不重复扣Δ营运资本 |
| 历史/同业对照 | 同公司变化与外部表征相互检验 | 交代准则、产品组合、费用分类和金融范围 |
| 滞后诊断 | 同报k、有效n、共同趋势、断点、右删失 | 相关高不等于时滞因果或物理转化率 |
| 反例 | 同一指标方向对应另一经营过程 | 旧例仅限制推断，不确认本期原因 |

旧列示净利润是否已经扣少数股东、固定资产净值/净额、CIP减值/重分类、预收的余额/流量、商品名称/价格类型都是高价值口径检查点。长期趋势不靠一条跨制度CAGR消除断点。中位数、年度比率均值、累计比率分别保存。价格比应同SKU/平台/日/类型匹配后统计，不把中位数之比当比值中位数。

## 判断与故事写法

给一句有边界的判断，再用两三组关键证据解释过程，指出替代解释、后续区分变量及预测含义。故事保留行动者、责任和时间，不虚构访谈或动机比例。长周期业务可分生产成熟、需求承接、资金回收三个时钟，按业务适用，不强套。

品牌/优势沿“形成机制→价格/选择表征→收入利润现金→替代解释→可持续条件”研究。高毛利不直接证明独有性；低销售费率也可能因外部渠道承担成本。经营兑现和市场传播/预期分开，市场故事只有连接到可识别经营变量时才进入业绩情景。证券估值另需价格、索取权、资本成本及隐含预期，不能把好公司当买入结论。

参考HTML先对照问题、原数据、统计量、解释和当前覆盖，必要时读实际字面量数据及配套原件。吸收内容不是换皮，新增图数不是内容完成率。可以复用有用问题，同时拒绝其错误口径；不执行参考旧工作流或复制HV/SCX身份。

## 把解释落实为未来参数

分历史可获信息、后验资料和当前未来；用最新合适有效基期建新预测，不回填旧判断。逐层拆供给/成熟库存/释放安排→销量×组合ASP→毛利/费用→利润→再投资/现金。单年产量滞后映射可作供给线索，不是全年销量硬上限，缺少分龄与损耗时不造转化系数。

参数列含义、年份/单位、幅度、来源类型、选择理由、修改触发条件。压力/基准/修复是经营条件世界，没有依据不给概率或统计置信区间。保留未建模项的基期假设；增量利润保留率不是税率Fact，现金转换敏感性不是实体现金模型。

计算至少一个能改变理解的门槛/敏感度，如量增q下维持收入需要p≥1/(1+q)−1；费用率变动对支出的影响为匹配收入×费率变化。新实际结果先分解误差来源，再改机制和参数，不只调总增速贴合曲线。

## 图表与阅读层

| 要看什么 | 优先图形 | 阅读检查 |
| --- | --- | --- |
| 年度变化 | 线/点 | 缺值断开，定义断点和后验/预测分开 |
| 两类/两期差距 | 并列柱/阶梯/哑铃 | 同量纲、零基线、精确端点、空实图例 |
| 总量与组成 | 堆叠/条带 | 总高度或厚度、层序明确；小项不消失 |
| 驱动贡献 | 贡献桥 | 输入/起终点/正负号可勾稽 |
| 两变量/阶段关系 | 散点/年度垂线 | 点标签、样本与阶段；不默认因果拟合 |
| 未来条件 | 场景线/参数实验 | 假设可改，模型缺口可见，不伪装概率 |
| 机制全景 | 带跳转的思维导图 | 节点身份、依据、Unknown；连线非因果证据 |

每幅图至少有研究标题、范围/单位、含义/用途/推断分析、精确数据/公式和来源批注。正文讲机制，折叠层容纳细节。多系列标签可适当减少，用悬停和数据表保留精确值，不为“完整”制造重叠。

样式切换复用同一数据与断点。实际截图检查并列标签、深底文字和浅色曲线；SVG全局CSS可能覆盖局部fill。桌面、窄屏图内滚动/键盘、整页不溢出、打印、减少动画、来源/节点跳转和预测控件按改动检查。离线不依赖CDN；图形动画不产生新数据。

## 文件与协作

原件→真实核验/来源绑定→精确计算→研究规格→作者故事/图形/内容层→HTML与人工反馈分别保存。当前指针只导航，Fact仍从原API动态读取。叠加层不静默改旧图数字、旧认可或依据绑定；新公司只带方法，不带上家公司参数和授权。

跨窗口最少保留来源/定义/单位、选定输入、精确计算及依赖、版本/信息集、真实核验身份、冲突处理/影响、图表覆盖和下一步。CURRENT短，方法和底稿按需读；不全文重扫/重核。用户核验按同源同口径批量呈现和固化绑定，只记录明确回复，旧有效数不反复问。

每轮优先补最能区分机制的资料，而不是无止境扩充图表。交付研究解释及其反证、参数和可复算结果；研究判断、人工采纳、合同关闭与签署各自登记。发布按实际授权，中文成果、正确仓库和选定清单，原件/完整载荷依用户约定留本地。
