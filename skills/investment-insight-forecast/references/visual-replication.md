# 参考HTML图形的复刻与迁移

适用于用户喜欢附件图像、希望用其视觉语言改进现有报告。先看参考图实际截图和绘图代码，再选择适合当前研究问题的编码；原件不改，数据仍来自当前项目有效来源。

| 图形语言 | 适合表达 | 需要保持的含义 |
| --- | --- | --- |
| 细线与年度点 | 同口径年度趋势 | 缺值断开；定义断点分段，期后观测另示 |
| 阶梯刻度 | 单变量大小、相关系数等 | 格数是辅助；最后端点与标签用精确值，不将数值取整 |
| 双列阶梯 | 同一年度两项可比量/率 | 单位与轴一致；毛利率差不升级净贡献 |
| 哑铃对照 | 两期/两类或t与t+k并列 | 空心/实心图例明确；生产与未来销量不命名转化率 |
| 构成条带 | 正金额/数量的年度组成 | 总厚度编码总量，位置无经济含义；层次与图例顺序一致 |
| 单期构成条带 | 一个时点的结构 | 小分项独立标注，不因面积小而遗漏 |
| 离散茎叶 | 不宜直接连线的年度水平 | 不假画固定样本趋势或补中间观察 |
| 垂线散点 | 两项变量的年度关系 | 点与阶段标识清楚；不自动画因果拟合线 |
| 阶梯贡献桥 | 可勾稽的两项贡献和总变化 | 先验和式，贡献累计，总项回零基线 |

按来源记录图型原型、颜色、编码和迁移理由。当前实现为`companybench/visual_charts.py`，每图`visual`元数据经`apply_chart_designs`叠加，不能覆盖旧图数值；新图必须引用当前已绑定计算或Fact，不从参考包搬HV/SCX身份。

连续条带遇缺值或负数停止，不补零。平滑只在观察点之间作为绘图连接，不能当新数据；分类变化处断开并说明间隙非零。刻度范围、颜色和字形均需有文字标签；图表信息不能只靠颜色。

复刻配色、留白、点线与节奏，保留当前数据修正。参考概括若与当前完整序列不符，写明差别，不能为了像参考图调整数字。高毛利差的范围、年度样本、单位和分母仍需按当前来源解释。

成果保留图表分析、数据口径、图型编码三层；重播只影响SVG动画，不改数据。无网络依赖，支持减少动画偏好和完整打印；窄屏用可键盘聚焦的横向图形容器保持标签可读，同时避免整页溢出。

交付前检查实际桌面/窄屏截图、路径、定义分段、图例对应、精确端点及重播；对新增数值图代码检验缺失/负数、贡献勾稽和输入不变。独立图鉴通过`render_visual_gallery`从当前图册择图生成，可随公司builder或通用CLI重建。
