# 经营、资本与现金参数

| 输出 | 明确输入和范围 | 不可混淆 |
| --- | --- | --- |
| 产品组均价/吨成本 | 同产品收入/销售量；同产品营业成本/销售量 | 组均价含结构，不是同 SKU 净价；吨成本不是当年基酒生产现金 |
| 经营利润小计〔分析口径〕 | 营业收入−营业成本−税金及附加−销售−管理−研发 | 不等于报表营业利润；还需财务费用、收益、减值等桥接，不自动为 NOPAT |
| 非现金营运资本 | 经营非现金流动资产−经营无息流动负债 | 现金/证券/付息债务/财务公司金融项目单列；“其他”逐项裁决 |
| 再投资 | 同经营范围 Capex−对应折旧摊销＋ΔNWC | Capex 现金≠资产净增；存货、合同负债已进入 NWC，不重复加减 |
| NOPAT | 调整经营利润−对应经营税负，或说明适用税率假设 | 合并所得税率含金融/非经营项目，不直接等于实体经营税率 |
| ROIC | 同范围 NOPAT/平均投入资本 | 不配错主体；明显季节性或分母异常需另解释 |
| 增量回报 | 成熟窗口 ΔNOPAT/相应 Δ投入资本 | 长周期投入不强制同年；分母零/负/近零停止机械百分比结论 |
| 实体调整 CFO | 合并 CFO−带符号、含合并抵销的财务公司净贡献＋有依据调整 | 财务公司单体 CFO 不等于对集团净贡献；拆不出则 Unknown |
| 自由现金代理 | 调整实体 CFO−同范围经营 Capex | 不自动命名 FCFF/FCFE；CFO 路径不再扣 NWC |
| FCFF | NOPAT＋D&A−经营 Capex−ΔNWC〔必要时另调其他非现金经营项〕 | 全部输入同范围；从 CFO 起算不能混用此路径 |

维护/扩张 Capex、经营税率、金融拆分、库存库龄、SKU/渠道费用归属不足时，保留具体缺口而不设置无依据比例。预测期、销量/净价/结构、资本周转、WACC、永续增长、净债务/非经营资产、少数权益、股数等为显式模型输入或 Forecast；不能从课件示范直接采纳。

观察期与资料可获时点独立。历史实际值、Agent运算、人工算术核准、预测假设分开；换范围或公式只重查受影响依赖。公式和舍入使用原始精确值，显示亿元或百分比时保留转换说明。
