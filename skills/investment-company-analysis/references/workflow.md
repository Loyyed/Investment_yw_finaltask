# 新公司进入分析的执行流程

## 先明确交付，而不是默认套课程

读取用户目的、实际合同与材料截止。任务含“帮我、开始、完成”时直接推进。合同原件保持，建立“条款→所需证据→底稿→成果→验收依据”映射；无合同就用通用研究计划。先辨认研究是经营机制、财务诊断、行业比较或另含估值，报告深度据此调整。

真正缺失且影响目标的公司主体、截止日期、材料范围可集中询问；证券代码、姓名或最终签署通常不妨碍独立研究。用户已经选定问题或给出授权，不再重问。可先按现有年报定义能完成的问题，再标出外部补证缺口。

## 首次材料识别

导入原件，登记SHA、格式、来源编号、版本/期间与用途。ZIP保留原包和成员关系；UTF-8/GB编码名称尽量恢复，但最终用途以正文标题、目录、表格与任务内容判断。重复字节合并登记，不重复当证据；Apple元数据可单列/跳过，不当研究正文。

先识别合同、主课件/补充读本、原年报、工具说明、模板与图片等角色。逐份判断能支持什么，写docs/source-map.md。工具执行只对确需使用的程序开展，不因压缩包包含脚本便盲目运行。导入/解包成功不是已经读完内容。

文本可索引；扫描PDF需查看图像/OCR，Word、表格、幻灯片按格式使用可用工具。已有对应专业技能时采用；缺包先利用现有环境，下载确需按当前授权处理。原文关键数字、空白列、单位和表头应视图核查；不把PDF摘要当来源。

## 研究推进与输出

| 阶段 | 做到什么 | 应留下什么 |
| --- | --- | --- |
| 定位 | 找到与问题匹配的原表/主张，记录版本、页码及交叉披露 | 来源地图、候选原值、阅读覆盖 |
| 提取 | 保留报告原字面值、单位、本期/上期、主体与范围 | 结构化候选；机器匹配不自动Fact |
| 口径 | 比较候选定义，用途裁决与原值核验分开 | 采用/结构/补充/排除理由，真实初选与修正 |
| 变化 | 两期原值与七项可比性明确后，原值代入公式 | 重述/冲突、公式及舍入、停止原因或已核结果 |
| 三维 | 明确问题，提出机制、变量和反证，与已核数字相连 | 矩阵、经济图、优势五步表、行业五步 |
| 财务接续 | 按实际目的将假设落到费用、平均资本和现金 | 已能回答的结果、无法直接分配的部分、下一检验 |
| 交付 | 先给直接结论，再给证据边界与后续操作 | 中文报告、来源/计算附录、内容验收、精简交接 |

同一事实可用于不同问题，复用当前绑定；不要为每份报告复制一套相互冲突的人工状态。叙事矩阵每行回答：问题、来源、状态、机制、变量方向/时点/口径、替代解释、反方、支持边界及后续。

一次优先完成高价值问题：例如与实际主营相连的收入来源、核心收益能力和最重要竞争优势。时间/资料有限时说明覆盖范围，把尚未完成的独立要求列出，不以三维模板自动声称全部合同关闭。

## 接手已有项目

读CURRENT与当前成果，调用Fact接口，再读取本次所需源页和合同。只对受变更影响内容修订；历史条款、真实用户原话和修正留存。当前入口明确标哪个版本有效，旧“待核”表述作为历史，不让用户在多份文件间猜当前状态。
