## 2. 全局研究地图：先知道自己正在回答哪层问题

公司研究回答企业怎样经营、盈利及承担风险；证券研究还要解释索取权、当前价格与隐含预期、期限及组合约束。估值是依据现金流和风险估计价值；定价是市场在特定时点形成价格并反映预期。公司优秀不能直接推出证券值得买。

完整路径：定义问题与时点 → 来源与口径 → 经营四环节 → 行业与优势 → 历史财务检验 → 条件预测 → 价值估计 → 价格隐含预期 → 风险与组合约束 → 人工决策及复盘。

Lec01—03充分支持前五步的研究方法，后面的完整估值、FCFF/FCFE、资本配置、仓位模型是接续模块；本轮未见相应独立课件或合同，不能声称已完成课程学习。材料不足时行动可为继续研究/暂缓判断，而非现实买卖建议。

| 类型 | 怎么写才可审阅 | 何时不能升级 |
| --- | --- | --- |
| Fact | 已核原文/已核算术，附版本、期间、单位、主体、位置、核验人和边界 | 候选、机器匹配、导出和旧摘要不形成新Fact |
| Interpretation | 事实如何支持机制；至少一种替代解释和反证 | 相关性不能充当净因果；管理层自述只能先证明其这样说 |
| Forecast | 条件、期限、量价成本资本假设、观察指标、失效条件 | 不把未来目标当已实现事实 |
| Decision | 人工在价格、风险、持有期、流动性和组合约束下选择 | 未有价格或约束时不敲定投资行动 |
| Unknown | 缺什么、查过哪里、影响哪项判断、下一取证动作 | 不用行业常识、网络摘要或顺口叙事补数字 |

## 3. 证据链与学习批注：每个数字都能解释自己

Lec02六个核验问题：哪份版本；哪页哪表哪段；本期和比较期；单位；合并/母公司/分部主体；脚注、政策及上下文。PDF物理页与正文印刷页分别记录。MD/OCR只是检索缓存，核验回原件。

操作补充：每条数据使用固定批注卡：编号；原文件及SHA；披露日期和信息截止；报告期/时点；PDF物理页/正文页；表名、行列和必要原句；原字面值；单位币种；主体/业务/渠道范围；空白处理；核验身份及原话/事件；用途；能支持与不能支持什么。计算再加输入编号、公式、代入、单位倍率、代码版本、舍入和停止原因。

事实链是“文件 → 指定单元格 → 候选 → 原文核验 → 适用口径 → 运算 → 解释 → 人工裁决”。真实原值可以因研究用途不适合而被排除，排除不等于撤销原值。来源或运算改变时只重核受影响依赖，保留旧事件与错误版本。

## 4. 商业模式：把赚钱过程拆成四环节

### 4.1 收入：卖给谁、卖什么、怎样收费

Lec03 3.1的收入三乘数：市场需求数量 × 同范围数量份额 × 平均售价。若行业输入本身是销售金额，再乘价格会重复计算。市场定义要固定产品、价格带、地域、客户、时间和计量单位。TAM为理论总体市场，SAM为公司能服务的部分，SOM为竞争与执行约束下可获得的部分。

先按产品、地区、渠道、收费机制分别列收入及对应成本。不同维度是同一收入的不同切面，不能相加。显性会员/服务费与商品价格、利差等隐性收费，须同时核收入确认与成本承担方式，才能比较单位经济。

产品组ASP = 匹配销售收入 ÷ 销量。它能观察组单位收入，组内产品和渠道结构变化也会影响ASP；不能等同固定SKU终端成交价。提价检验要同时看同规格价格、销量、份额和竞品；缺行业分母就不知道份额。

操作补充：可用恒等式R=Q×P做描述分解：ΔR=P₀ΔQ+Q₀ΔP+ΔPΔQ；同范围的剩余交叉项单列。数据必须有匹配收入与销售数量，这只能拆算术贡献，不能自动识别提价因果。

### 4.2 成本：新增收入付出了什么代价

毛利率=(收入−匹配营业成本)÷收入；毛利不含所有经营费用，不能代替净利润或单客户贡献。最小经营单位可以是商品、门店、会员或订单；单位贡献=单位收入−直接成本−可归属增量经营成本，另核获客、履约与必要费用。

经营杠杆是收入变化对经营利润的放大，不是利润同比除收入同比就能证明固定成本机制。检查折旧、租金、薪酬等刚性项目，同时看上行与下行；价格、组合、一次性损益、会计分类都可能形成替代解释。

规模经济看收入或产销量扩大后单位固定成本、费用率是否持续摊薄；资本密集度看维持和新增业务需要的资本。二者不同。折旧摊销是资本需求线索，需与资产、投资和产能利用交叉核验。

操作补充：营业成本÷销量叫每销售单位成本；营业成本可能对应早年生产、储存和存货结转，不得直接用当期产量推成当期制造成本。生产成本桥接要有期初期末、投入、产出、酒龄/在制、减值和分类；假设不齐只能附条件算术。

### 4.3 资本与再投资：增长占用了多少资金

课件表达：再投资=净资本支出+非现金营运资本变动；净资本支出=资本支出−折旧摊销。经营非现金营运资本应剔除现金、证券和付息债务，同时逐项判断经营属性。

资本支出、项目当期投资额、资产账面存量、在建工程增加不是同一东西。购建长期资产现金也未必等于完整资本支出。维持性/成长性投入若未披露就单列Unknown。

再投资率=再投资÷NOPAT；ROIC=NOPAT÷投入资本；增长≈再投资率×ROIC只在资本回报与口径等条件相对稳定时作为模型近似。更关键的是新增资本回报；ROIC高低要与资本成本比较，缺资本成本就不敲定价值创造。

操作补充：年度利润通常匹配平均/期初资本并说明选择。课件3.3同时使用存量销售/资本和边际Δ收入/再投资两个观察口径，执行时必须分栏；用存量比率估算边际投入需要额外稳定性假设。并购、租赁、研发资本化、负经营资本或接近零分母都应另检验，金融行业不套工业ROIC。

### 4.4 利润到现金：账面结果是否成为现金

折旧摊销不等于当期付现；应收和存货增加可能占用现金；应付、合同负债可阶段性释放现金；购建资产实际付现。现金转换比率必须分子分母主体一致。

集团CFO÷集团全部净利润反映集团现金/利润关系；集团CFO÷归母利润可作特别定义的描述比率，但不能混称同实体标准转换率。金融子公司的存贷款、同业往来等可能改变集团CFO，扣掉列示金融项的余额仍不保证是精准主营CFO。

CFO−指定购建长期资产现金只叫简化现金余量，不能冒称完整FCFF/FCFE或全可分配现金。存货增加也可能来自正常工艺和陈酿，不直接等同终端滞销。详细三表勾稽、FCFF/FCFE、DSO/DIO/DPO为后续模块。

## 5. 行业五步：从边界到失效条件

| 步骤 | 初学者应完成的动作 | 应留下的证据或缺口 |
| --- | --- | --- |
| 定边界 | 画产业链；写产品、地域、价格带、客户 | 哪个环节赚钱、上游和下游、统计分母是否匹配 |
| 分阶段 | 比较3—5年需求数量、渗透、进入退出、集中度 | 阶段为带边界Interpretation；高渗透不自动衰退 |
| 找核心 | 按阶段挑真正的约束 | 导入：真实付费需求和单位经济；成长：空间及扩张效率；成熟：竞争、利润池和价值捕获；衰退：替代速度、存量现金和第二曲线 |
| 验逻辑 | 将机制一一对应经营和财务变量 | 不只挑有利年份；量、价、利润、资本和现金共同检验 |
| 防风险 | 为核心解释选1—3个观察量并写传导 | 高频不等于领先；明确方向、阈值依据、反证与复查动作 |

行业增长不必然转成股东回报。CRn高不等于价格竞争弱；收入最大的产业环节也未必获取最多利润。宏观/监管/技术新闻只有沿“外部变化→行业变量→公司经营→财务”形成具体路径才有解释用途。

## 6. 七类竞争优势：同一条可反驳链

通用链：优势来源 → 影响机制 → 可观察结果 → 模仿壁垒 → 反证。护城河三问：优势多大、持续多久、扩张后能否保持。分类框架只帮助取证，不能证明优势。

| 来源 | 主要观察量 | 替代解释/反证重点 |
| --- | --- | --- |
| 品牌 | 可比溢价、提价后销量和份额、跨期利润率差 | 高端产品/渠道组合、成本变化；溢价缩小、销量弱、营销或库存增加 |
| 成本与规模 | 单位成本、费用率、产能利用、利润率和资本回报 | 资源价格周期/减投入；产能增却利用率与回报下降 |
| 网络效应 | 活跃与交易频次、留存、CAC、ARPU、两侧互动 | 注册量/补贴并非价值；多宿主、活跃下降、获客变贵 |
| 渠道分销 | 单渠道收入、同店、费用/获客、库存、排他期 | 网点数不等于效率；共享渠道、协议到期、新增渠道不赚钱 |
| 技术 | 研发费用化/资本化、新品贡献、迭代时差、减值 | 专利量不是经济价值；旧资产损失、新品接续失败 |
| 客户转换成本 | 续约/流失、NRR/ARPU、迁移和实施成本 | 留存来自折扣/短合同；标准接口、低成本迁移和集中客户风险 |
| 牌照监管 | 准入/新增资格、续期、定价与资本约束、回报 | 限制进入可能同时限制利润；扩容、开放或续期失败 |

保留与公司最相关的主张，避免强套七类。每条解释至少并列一个合理替代机制、一项能削弱自身判断的材料要求，以及缺失环节的Unknown。

## 7. 每年重大变化是研究主线

操作补充：建立年度事件表，不预设所有年份都正常可比。每年检查会计政策/重述、合并范围、并购处置、产品/渠道分类、提价、产能/投产、库存/账龄、现金管理、资本配置、关联交易、审计与治理、监管技术变化。

流程：发现异常 → 登记原报告及页码 → 分开公司原因自述与分析解释 → 核对比较基数及分类 → 决定重建序列或停止 → 检查受影响的每条机制与计算 → 更新反证及人工待裁决项。

同比异常只是取证信号。正基数同比=(本期−前期)÷前期；零基数停止；负基数用绝对变动和亏损收窄/扩大说明。毛利率从a%到b%的变化写b−a个百分点，不能与增长百分比混用。重述未桥接不硬拼CAGR。

## 8. 人与Agent、材料与网络的分工

Agent读取、定位、整理、提取线索、运算和反方自查。人工核实新要求所需事实、决定研究口径、审阅机制、敲定结论与实际签署。历史明确代理授权可在原范围内继续使用，身份保持Agent；它不等于本人核验，也不自动授权新公司。

用户本轮八条规矩落实为：附件优先；每项数据可批注；算术可复算；解释有证据、替代与反证；缺证不知道；流程先学原文再学算式；中间产物可接手；跨年变化必查；合同可扩展但保留原要求。

网络仅用于术语解释和新闻旁证。联网材料另存获取日、发表日、事件日、链接、原始发布者、用途与报告期归属；它们不能填附件缺失的数字、替代原件或自行成为核心Fact。本轮学习阶段没有使用网络。若外部证据是唯一支持，机制仍是待检验，先申请/等待纳入材料范围的实际确认。

## 9. 换Agent时怎样继续

先读CURRENT，再按问题读本文件对应节与第二份流程交接；调用当前公司Fact接口；打开本轮所需原页；复算受影响公式；更新Unknown和人工裁决卡；保留真实修正。不要为了“继续学习”重新全扫项目或全文读日志。新公司复制方法与空模板，不复制茅台数据、授权和机制结论。
