# 既有分析凝聚出的经验与失误修正

| 实际易错点 | 可复用做法 | 对操作体验的影响 |
| --- | --- | --- |
| ZIP解出来名字乱码或无意义 | 原包和成员关系保留，尝试解码后按正文/目录/表格判用途 | 用户只导入材料，不承担整理命名 |
| 把机器匹配、开窗或校对文字当核验完成 | 候选提取、实际确认与当前Fact分开，明确真实动作 | 一次点击/实际聊天确认即可同步账本，不让用户改JSON |
| 集团、母公司、净利润/归母、利息项目混用 | 先比较口径与用途，原值真实性和适用性分别登记 | 排除替代不会删除已核原值，后续用途可调整 |
| 把不同切面的收入相加或硬凑范围 | 分产品、渠道、区域与主营/其它分别保留，先看各表头 | 同一数据不重复造“新事实”，合计差异有说明 |
| 重述比较数与原报数混算 | 保留版本、七项可比性和冲突，不硬拼统一序列 | 只暂停受影响运算，其它任务继续 |
| 因无固定SKU/终端量就否认均价可计算 | 收入÷匹配销量算产品组均价，再分开因果与终端解释 | 用户问题得到直接计算答案及有用边界 |
| 用生产量作销售均价分母，或成本÷当年产量当生产成本 | 销售/生产/基酒/成品和时间匹配；真实生产成本单独桥接 | 统计结果与假设真值分开核准，不反复要求否定已核算术 |
| 单位成本上升就断言没有规模经济或撤销品牌定价权 | 投入价、组合、产能、时滞等替代；成本与品牌路径分开 | 尊重用户已选研究问题，给反证而不擅改其判断 |
| 高毛利直接写成品牌因果/长期护城河 | 走优势五步，价格与需求、维护费用、资本及模仿对照缺口明确 | 可保留有证据的暂定Interpretation，避免空泛标签或一味拒答 |
| 全集团CFO解释主营收现，CFO减支出叫完整FCF | 匹配集团净利润，单列表列金融/其它影响，余额范围写清 | 提供能算的结果，不虚造分部现金与ROIC |
| 空白本期列被上期数填入 | 查空间列和原图，空白与本模型按零分开 | 关键错误自动暴露，旧源字节和修正留存 |
| 跨年行业绝对数和原报同比冲突却强画趋势 | 每报引用原值与同比均保留，未桥接就不算CAGR/市占率 | 图只呈现适当可比内容，用户看到限制及处理理由 |
| 全部公司一律判成长/成熟或套消费行业指标 | 按广义/细分、周期/生命周期、业务性质适配 | 新公司模板有结构，没有预设答案 |
| 多套候选、缓存和人工状态互相冲突 | 统一来源绑定事实接口，旧事件与导出各司其职 | 页面展示当前状态，历史待核文字不会混充现状 |
| 用户已认可内容却反复问同样问题 | 实际授权/审核绑定当前版本，未变记录复用 | 聚合一次审阅，变化才复核相应内容 |
| 回滚/弃用导致真实历史丢失 | 新提交或明确弃用标记保留旧版本；不为“整洁”删除修正链 | 可重新核验又可追溯，中文提交说明最终改动 |
| 全部日志当下次上下文、每次全盘扫描 | CURRENT只存当前节点与索引，来源接口仍独立核真 | 快速接手，详细数据留文件按需读取 |
| 上家公司授权被写成所有公司永久规则 | 新项目独立初始化，委托必须来自本项目实际动作 | 复用方法与操作，不误迁移身份、数据或结论 |

重要纠正原则：更专业的文字可以由Agent整理，但保存用户原话与Agent限定的分别署名；没有发生的核验、签署、错误不能为了满足模板编造。真实事实和真值范围不足时保留Unknown，目标是给用户可用的研究结果和下一步，而不是把每个空格填成肯定结论。

程序和证据复杂度放在后台；用户端保留查看原件、确认、保留疑问、审阅报告四类动作。新增独立核准范围用真实明确授权一次登记，不让用户承担版本绑定和状态同步。
