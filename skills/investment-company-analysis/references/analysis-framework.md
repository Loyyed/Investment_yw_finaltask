# 三维问题与机制证据框架

## 商业模式：收入→成本→资本→现金

从实际主营和客户出发：谁购买什么，公司靠什么取得收入，承担哪些直接成本与期间费用，增长需何种资本，收入/成本确认与现金投入/回收何时发生？图箭头是经济联系，不是简单会计减法。

先业务，再产品/地区/渠道；直接归属与未分配分别列。解释品牌、渠道、工艺/储存等本公司相关路径，路径选择不固定套三条：例如工业公司可用订单、产能利用、服务；金融公司可用资金来源、风险定价与资本约束。

每条路径有四个检查：①收入/需求或净价是否受影响；②获取该收益的成本/费用；③平均资本与时间占用；④真实收付款与风险。高毛利不能跳过维护费、资本和现金，直销价差也不能跳过产品组合与履约。

输出业务边界表、经济逻辑图、路径变量表与Unknown分配表。利润不等于现金从库存、收入确认、回款/预收、采购应付、资本支出及其它业务流量解释；仅作条件路径的条款不能说成已经核实的公司收款制度。

## 行业竞争：定边界→分阶段→找核心→验逻辑→防风险

| 步骤 | 核心问题 | 交付及防误用 |
| --- | --- | --- |
| 定边界 | 产品/客户/地区/价格带/替代，处于产业链何处？ | 工作边界与已证实相关市场分开；确定份额分子分母是否可比 |
| 分阶段 | 多期需求/总量、价值、渗透、集中、进入退出能支持哪个阶段？ | 成长/成熟/衰退为有证据的Interpretation；广义与细分、生命周期与周期分开 |
| 找核心 | 行业价值由谁创造和获取，竞争主要卡在哪里？ | 根据价格、质量、效率、资金/技术约束或获客确定可回答问题 |
| 验逻辑 | 公司结果是否与主张一致，有何替代解释与反方？ | 公司增长不等于行业成长或份额提升，内部表现不冒充同行排名 |
| 防风险 | 什么信号会削弱当前判断，如何观察与处理？ | 时点/口径明确的反证条件，条件安排不说成已经发生 |

成熟阶段可以同时有收入利润增长和结构升级；产量趋稳/下降也可能有周期因素。多年度原报告能加强判断，但同一公司的重复引用不是多个独立行业来源。缺细分分母或竞品数据时，完成当前资源能支持的裁决，说明相对优势未证，而不是编造份额。

## 竞争优势：优势来源→影响机制→可观察结果→模仿壁垒→反证条件

优先研究最重要的一项，与用户已选问题一致。品牌、成本、转换成本、网络效应、许可证、资源或技术等必须具体化，不能用标签直接当结论。

1. 来源：何种资产、关系、资源或能力？公司自述只证明它提出该主张；消费者/客户认可、权属或成本优势另证。
2. 机制：通过支付意愿、需求弹性、交易留存、单位成本或风险定价等变量，影响谁和什么收益？区分其它共同原因。
3. 结果：方向、时点及口径是什么？观察跨年/提价事件、可比组或同行。可计算组均价、高毛利与量价关系作为描述线索，不要求必须先得到因果实验才允许算。
4. 壁垒：竞争者为什么不能快速复制或绕过？时间、资本、权利、学习/关系成本可成假设，同时检查已有储备、合作替代与其它工艺。
5. 反证：出现何种可观察变化时收窄/撤回？净溢价收窄、相对终端需求下降、维护费抵销收益、资本回报弱化、客户迁移或竞争者绕过。

“公司将品牌列为核心竞争力”“组均价增加”“毛利保持”可分别为Fact；“品牌暂时形成定价权”可以是Interpretation；“纯品牌因果、长期忠诚、独有壁垒充分证实”在缺对照时仍Unknown。用户维护的判断与Agent提出的限定各署其作者。

## 接续与报告

每条主张沿“问题—证据—解释—边界”写底稿，结论引用有效ID。需要财务结果进一步验证的费用、产能、存货价值、平均资本、ROIC或完整现金流，按本次目的推进或明确接续。未提供的后续课程合同不编造。

报告先给三个直接答案，配跨年图或经济链图，再给证据、反方、Unknown及其影响。没有证据时保持可反证的工作判断，完成内容与签署分开。用户已审阅章节保持原文快照或明确版本绑定，后补证不能伪称以前已经逐项人工确认。
