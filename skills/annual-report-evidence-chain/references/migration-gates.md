# 时序与指标迁移关口

| 关口 | 检查 | 停止/区分 |
| --- | --- | --- |
| 报告期 | 标题、表头、起止日期、年度/半年累计/单季 | Q4 文件可能为年报；累计流量不与全年冒称同期间比较 |
| 版本 | 每期原版、比较列、修订版、公告日和研究截止 | 同报告比较列不等于独立旧年报；后来资料不能回填历史时点信息集 |
| 存流量 | 期末/期初余额，期间发生额 | 余额增量不是现金流；Capex 现金不是期末资产净增 |
| 主体 | 合并、单体、子公司/分部；金融与实体 | 同范围利润配同范围资本；不能集团利润配仅实体资本 |
| 指标族 | 收入/总收入/主营收入，利润/归母/单体，CFO/FCFF/FCFE | 同名或同数不证明等价；每一用途重审支持边界 |
| 可比性 | 定义、合并范围、币种单位、重述、非零基数 | 未桥接变化不核为可比同比；原值机械变化标明范围 |
| 分解维度 | 产品、地区、渠道各自成组 | 不跨维度加总；平台收入不代表全部直销 |

研究期与资料取得日分开。事后研究可用后续文件讨论演变，但各年份、观点与假设分栏；历史时点决策要求实际可获日，不知即 Unknown。负基数、零/近零资本增量分别说明，不能把异常百分比直接解释为改善。

合同字段、最低行数或公式不适用于新行业时，记“不适用条款—原因—需要的替代成果”；按当前用户授权建立扩展研究计划，不假冒教师批准新合同。
