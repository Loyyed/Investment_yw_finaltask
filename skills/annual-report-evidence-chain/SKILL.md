# 年报证据链

先读当前公司 CURRENT、AGENTS 与实际合同。只加载与本轮问题有关的材料和参考，不全文重读日志。方法可复用，旧公司金额、页码、编号、授权与结论不可迁移。

从压缩包接收材料时保留原包，登记包与成员 SHA、真实文件名、用途及 PDF/MD 对应关系。排除 __MACOSX、资源分叉与配图重复计数。文件名 Q4/Q2 不证明独立季度，按正文确认年度、半年累计或单季。MD/OCR 只定位，原件核验回 PDF；缺原件保留 Unknown。

每项指标建立身份卡：原文名称、经济含义、主体、合并/单体、表/附注、覆盖范围、存量/流量、期间/时点、单位/币种、来源版本、比较基数及研究用途。行列、脚注与分项合计按同维度检查；空白、破折号、零分别保留。采用、对照、排除是研究用途判断，不等于原值真实与否。

原值调用当前项目 ReviewStore.facts()；旧工作空间还分别调用 change_facts、m01_metric_facts 等独立接口。复用有效输入，无变化不重复询问。真实窗口或明确聊天确认只覆盖已呈现项目，保存原话、身份、上下文和绑定；不得制造窗口事件。源绑定变动只重查受影响项。

变化先查版本、期间、主体、合并范围、定义、币种单位、重述及比较基数。缺关键条件或无法桥接时停止“同口径变化”核准。原量机械差和来源自报同比可在用户认可的不同口径栏分别呈现，但不可称同口径增长。详见 [迁移关口](references/migration-gates.md)。

计算保留原数、公式、代入、未舍入值、显示精度和输入绑定，最后一步舍入。AgentCalculated 与人工变化 Fact 分开；结果不证明原因。原合同只做定位/提取时不加入毛利、机制、估值；扩展研究另外标记，不修改原合同。

节点交付包含当前成果、真实修正、Unknown、下一项人工动作和精简 CURRENT。已有正式签署不覆盖新内容；完成、内容认可、真实签署和教师批准分别记录。仅按本会话授权范围发布成果。
