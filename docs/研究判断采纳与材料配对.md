# 研究判断采纳与材料配对

原数核验完成后，向用户集中展示研究主张、机制、可观察变量、当前有效证据、运算、替代解释、反证条件及Unknown。明确哪些意见得到有范围支持，哪些仍不能确定，避免把“已核数字”直接升级成因果、经济价值、竞争壁垒或投资决策。

## 记录一次真实内容采纳

1. 保存不可变的审阅版本、展示指纹、来源绑定及已展示计算快照；当前结论与原展示分开。
2. 用户明确采纳后，独立记录实际原话、实际主体、时间含义、采纳项目及边界。没有另署名时保留未署名，不把以前的核验人或执行/复核签署移植为新签名。
3. 原数Fact账本、人工算术确认、研究意见、教师/客户批准和正式签署分别维护。Interpretation被采纳后仍为Interpretation，Unknown和反证继续保留。
4. 读取当前结论时重新校验原展示、实际答复、当前来源及计算语义。原数、期间、主体、单位、公式、精度或数值变化时，只让受影响意见失效并重审。
5. 排版、生成日期及输出哈希等展示元数据单独管理；只排除明确的展示字段，不能借语义比较忽略真正的研究变化。保留原快照和来源，以便重建用户当时看到的版本。
6. 完成节点同步当前导航、结论、报告、剩余缺口和精简交接。没有新原数待核时进入内容审阅；无法由材料识别的项目归因、净贡献或回报保持Unknown，避免无止境追加核验。

## PDF与Markdown配对

指定PDF是事实依据，Markdown是检索工具。压缩包与成员SHA、年度和标题分别登记；一般“章程修订”等正文关键词不能证明年报为修订版，文件名也不能单独证明历史更正内容。

检索稿的纯数字HTML单元格若存在内部空白，可在独立比较视图规范后回PDF原行核对。禁止改原件或把不同单元格的数字拼接。保留规范前后片段、原页及定位。数字集合相同、数值出现次数相同、全文一致和历史修订差异已经证实是不同结论，不能互相替代。

配对技术检查与正式材料版本批准分别记录。未取得原版/更正说明时明确历史差异未知；先判断这些年份是否进入当前计算窗口，避免让不相关的历史检索问题扩大为全部旧数据重核。


## 分段统计与渠道范围

年度定义或业务构成发生变化时，先报告完整观察窗，再同时列出有解释依据的分段窗口、实际年度、样本n和统计量。分段用于敏感性检查，不能挑选符号或最高相关系数来证明经营效果。样本少于3时停止相关系数；小样本和共同时间趋势的限制要保留，相关系数不是因果效应或显著性结论。

公司销售费用率的分子、分母须分别绑定原报表科目。“其中：营业收入”、含金融利息的“营业总收入”、母公司收入和主营渠道收入不能互换。公司费用率与渠道收入份额可以作有范围的描述对照，但公司费用不因此取得渠道归属；线上销售也不必全属于直销，按原定义区分。

主营渠道毛利、附注全营业收入分解和渠道净贡献分别列示。范围差额用于解释两表为何不同，不能改旧原数或据此命名某平台费用。缺少按渠道归属的费用、履约、回款和库存资本时，净贡献增减方向都保留Unknown；完成可计算研究后集中审阅判断及反证，不以主观收入比例分费来强行闭合合同。
