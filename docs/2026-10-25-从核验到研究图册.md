# 从核验清单到研究图册

2026-10-25。新增能力位于真正的通用工作台，具体公司数据仍留各自项目。

报告页新增“变化、机制与预测”入口：读取当前项目的版本规格，打开前用其原接口校验有效事实与来源/计算依赖，然后生成可交互HTML。旧依据汇编仍可使用。没有研究规格的新公司显示写作指引，不继承茅台案例。

生成命令：`python -m companybench.insight 公司目录`。标准项目加`--mode standard`。默认输出`outputs/证券投资分析研究图册.html`，逐章页放`outputs/research-atlas/`。`work/research-atlas-current.json`以`spec_path`指向当前版本；规格结构包括company/date/title/subtitle、chapters、sources、authority、dependencies、forecast和forecast_results。公司研究者填实际观点及来源，渲染器不会凭核验表自动编造机制。

章节包括问题、判断、机制论证、图表、替代解释、反证和下一步；数据表和来源批注可展开。预测使用产品量×公司组合ASP，结合毛利/费用形成条件利润桥；每年参数单列，支持压力、基准、修复及2026参数互动，具体起始年度随模型基期。页面明确假设、未建模项和金融现金限制。

本地门户仅对渲染器生成的图册开放带nonce的脚本策略，沙箱不授予同源权限、不允许网络连接或表单。导入原HTML仍按原下载策略处理。离线页面是生成时快照，不声称永远有效；从门户打开会重新核当前绑定。脚本不写ReviewStore，不增加人审或签名。

方法见[研究预测skill](../skills/investment-insight-forecast/SKILL.md)。公司案例的观点和数值不进入工具包。核心核验`core.py`维持原字节。
