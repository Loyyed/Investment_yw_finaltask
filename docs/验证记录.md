# 工作台验证记录

本记录验证通用程序和方法包，不代表已分析任何真实公司，也不代表投资结论验收。

## 已完成验证

- Windows、Anaconda Python环境：32项隔离单元与HTTP集成测试通过。使用临时合成数据，不带入真实公司项目。
- 创建独立项目、原件字节保留、去重、中文ZIP与传统编码文件名恢复，以及路径穿越、符号链接等拒绝规则。
- 来源替换或缺失、候选修订、计算输入撤回、程序计算规则变更会使受影响Fact失效；保留旧核准历史。
- 跨年可比性、单位和范围检查；披露空白保持空白，仅带明确边界的派生算术可按零计算。
- 人工与授权Agent身份分开，授权撤销、账本事件与状态投影一致性、过期页面绑定和本地操作接口保护。
- 报告确认绑定本版报告及实际引用证据；不相关候选不会使内容确认失效，签署状态仍待本人填写。
- 独立公司项目整体迁移后，可用随项目附带的方法与程序读取来源、状态和命令行。
- 独立公司Git可创建中文本地提交并忽略runtime；公司项目未建独立Git时拒绝误用父目录仓库，不自动推送。
- 实际浏览器检查：中文首页、三步入口、新建公司表单及空白项目状态。界面测试项目仅位于临时验证目录，不进入发布包。

技能结构另以skill-creator配套quick_validate.py检查。方法包执行`scripts/check_bundle.py`检查Python语法、本地文档链接、七份模板、必要入口和空白数据边界。发布时保存实际命令结果到被Git忽略的runtime，不把临时测试输出作为下一会话默认上下文。

## 可重现检查

```bash
python workbench.py doctor
python -m unittest discover -s tests -v
python scripts/check_bundle.py
```

测试数据只用于验证真实性规则，不是种子公司数据。用户新建项目默认没有Fact、授权或已验收报告。

## 实际边界

- 当前真实运行验证在Windows完成；Linux/macOS提供标准库程序与相对路径启动入口，未宣称已在这些操作系统实机测试。
- 核心操作不需要第三方Python包。PDF定位缓存是可选功能；Word、Excel、PPT及扫描PDF须由Agent利用可用的相应工具阅读。导入与文本提取不等于完整阅读。
- ZIP原件与成员会登记。嵌套ZIP需Agent继续导入具体成员；RAR/7z利用已有解压工具处理后再导入，仍保留原压缩包。未自动安装解压软件。
- 哈希及事件链检查能发现当前绑定与记录不一致，不能替代法定签署、独立审计或身份认证。
- 方法不保证自动得到任何特定投资结论；缺证、不可比或超出资料支持能力的部分应明确保留Unknown。
