# 工作台操作指南

双击根目录启动工作台.cmd，先新建公司或连接已有空间。左侧按材料、核验、计算、研究、报告推进；新手一次只核一项，熟练视图可检索表格。

完整操作及底稿位置见[全流程操作路径](2026-10-13-全流程工作台.md)。不得以界面显示文件完成代替Fact、研究结论通过或签署。

## 最常用操作

- 导入资料：材料与来源页选择文件，或填具体资料目录。原件归档与SHA记录，ZIP原包和成员关系保留。
- 核验一项：登记候选，打开原件，检查页码、原数、期间、单位、主体、范围和定义，实际点击确认。旧空间点击打开原核验窗口。
- 比较变化：建立计算候选，选有效输入，按公式顺序、分母与单位换算；同比逐项核可比性。异常写入年度变化／修正底稿后再算。
- 写研究：研究与合同页填写总判断和各章，保存草稿；命题分别写支持、挑战、替代解释、反证和引用ID。
- 整理合同：每份合同按原条款添加要求、执行状态和底稿，保留并行版本；记录实际检查，不会自动确认引用Fact。
- 做情景：填FCFF与明确增长、折现、永续、债务和股数假设。空字段不补数，模型值保持Forecast。
- 导出报告：生成本版，打开HTML审阅，下载MD／HTML／依据JSON，HTML可打印成PDF。旧版按摘要路径保留，不覆盖原手写报告。
- 签署：内容审阅通过后填写真实姓名、日期和身份授权，下载单列收据；同人执行／复核明确标注。

## 和Agent协作

复制界面的协作指令，让Agent先读AGENTS.md和当前交接，再按实际合同／目的深入阅读与计算。默认不替本人点核验按钮；已有真实聊天确认或本项目明确代理授权使用对应接口，如实记录核准身份。

CLI原值、核验、来源与Git命令见[证据与核验接口](../skills/investment-company-analysis/references/evidence-and-review.md)和[操作与报告](../skills/investment-company-analysis/references/operations-and-reporting.md)。本轮新增draft、model、report、link命令在全流程操作路径中说明。命令不自动创建人工确认或签名。

没有材料或口径未定时，保留Unknown，写需要什么、影响什么和下一验证。不要让使用者重复核验未变化的旧Fact，也不要把签名、数据量、管理层原话或算术当作因果证明。


## 现金与资本分析的核验顺序

1. 核对合并净利润、经营现金净额、购建长期资产现金及营业收入的主体、年度和单位。合并净利润含少数股东损益；期末账面存货金额与实物库存吨数分别处理。
2. 先做合并现金转换、CFO减购建现金、购建现金强度及账面存货强度。CFO已反映经营营运资本现金变化，再减同一ΔNCWC会重复扣减；回原报表现金调节表说明原因。
3. 金融现金行按原符号列示。少数已列金融行的净额不等于完整金融贡献，缺单体、分摊与内部抵销时实体CFO保持Unknown；CFO减购建现金不命名正式FCFF或可自由分配现金。
4. 另行裁定选择性NCWC、D&A、同范围NOPAT和投入资本。某项固定资产计提不自动代表完整D&A，“其他”项目不按经济性质猜填。先匹配利润与资本范围，再看平均资本和多年增量窗口；小/负分母、跨定义断点或成熟期不足时停止。
5. 有效旧输入直接复用，未核年度在面板逐年标缺口。课件示例、参考HV标签与复制来的签署不自动成为当前项目Fact；原数确认、计算、研究意见与正式签署分别记录。


### 成立、纳入合并和正式营业分别核查

研究某业务的影响前，分别回原文找出投资设立、首次纳入合并、取得资格/正式营业的年份。三者可能不同；合同划定的观察窗是研究起点，不能替代年报历史核对。出现冲突保留合同和旧记录，在修正表列原说法、原文页码、新候选解释、受影响的指标和待确认范围。

以业务开展前为代理窗时，已合并但尚未正式营业的一年也应单列检查；主窗和敏感性窗分开，不因剔除一项利息就认定其余利润、税与资本均属纯经营。断点原文核验、跨年可比性裁决及研究判断分别记录。

净利润到CFO调节表先核当期列、单位和正负号，再核各行加总与已核净利润/CFO是否相等。原表空白保留为空；如为已列项目加总而采用“该空白不产生加项”的约定，明示算术规则，不能将其改写为公司披露零值。CFO已经反映营运资本现金调整，从CFO出发不再重复扣同一变化。

### 资本代理分三步协作

先按年度和相邻页批量核原数，再单列科目经营归属、税率适用性、基期和平均资本，最后审阅计算与结论。营业利润乘报表有效税率只是一种会计代理；剔掉现金等资产后，仍须说明利润中的利息/投资收益如何处理。不能因原数全部正确就认定利润和资本同范围。

多年增量诊断同时写明起讫年、经过的年数、分母定义和业务成熟期。期末减期初资本不等于完整现金再投资；观察跨度未达到有来源支持的成熟期时，不给出已经成熟的高回报结论。平均资本需要基期原数，缺失时保持未知。
