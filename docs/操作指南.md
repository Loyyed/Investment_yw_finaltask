# 工作台操作指南

双击根目录启动工作台.cmd，先新建公司或连接已有空间。左侧按材料、核验、计算、研究、报告推进；新手一次只核一项，熟练视图可检索表格。

完整操作及底稿位置见[全流程操作路径](2026-10-13-全流程工作台.md)。不得以界面显示文件完成代替Fact、研究结论通过或签署。

## 最常用操作

- 导入资料：材料与来源页选择文件，或填具体资料目录。原件归档与SHA记录，ZIP原包和成员关系保留。
- 核验一项：登记候选，打开原件，检查页码、原数、期间、单位、主体、范围和定义，实际点击确认。旧空间点击打开原核验窗口。
- 比较变化：建立计算候选，选有效输入，按公式顺序、分母与单位换算；同比逐项核可比性。异常写入年度变化／修正底稿后再算。
- 写研究：研究与合同页填写总判断和各章，保存草稿；命题分别写支持、挑战、替代解释、反证和引用ID。
- 整理合同：每份合同按原条款添加要求、执行状态和底稿，保留并行版本；记录实际检查，不会自动确认引用Fact。
- 做情景：填FCFF与明确增长、折现、永续、债务和股数假设。空字段不补数，模型值保持Forecast。
- 导出报告：生成本版，打开HTML审阅，下载MD／HTML／依据JSON，HTML可打印成PDF。旧版按摘要路径保留，不覆盖原手写报告。
- 签署：内容审阅通过后填写真实姓名、日期和身份授权，下载单列收据；同人执行／复核明确标注。

## 和Agent协作

复制界面的协作指令，让Agent先读AGENTS.md和当前交接，再按实际合同／目的深入阅读与计算。默认不替本人点核验按钮；已有真实聊天确认或本项目明确代理授权使用对应接口，如实记录核准身份。

CLI原值、核验、来源与Git命令见[证据与核验接口](../skills/investment-company-analysis/references/evidence-and-review.md)和[操作与报告](../skills/investment-company-analysis/references/operations-and-reporting.md)。本轮新增draft、model、report、link命令在全流程操作路径中说明。命令不自动创建人工确认或签名。

没有材料或口径未定时，保留Unknown，写需要什么、影响什么和下一验证。不要让使用者重复核验未变化的旧Fact，也不要把签名、数据量、管理层原话或算术当作因果证明。
