# 使用与移植操作指南

## 日常操作只用窗口

启动工作台 → 填公司名 → 添加原件 → 复制Agent开工指令。候选准备后查看原件并点击确认，或者点保留Unknown；报告准备后审阅本版结论。证券代码和姓名均可后补，用户不需要手工写JSON。

窗口的“授权Agent核准”明确适用于本公司当前及后续原披露、算术，可另选内容验收。撤销按钮使相应代理确认不再当前有效，真实历史保留；此前本人确认不受误改。Agent仍要实际读原文并核口径，不自动批量批准，也不代写签名。

候选的来源、期间、主体、单位、定义由Agent准备。缺字段、原件变化、未核计算输入、错误分母或不可比时，确认按钮会阻断并显示具体原因。修改以后仅对应条目需复核，旧确认不删除。

报告审阅是本版文件与实际引用证据的内容认可，机制仍为Interpretation，Unknown继续明确。签署另看docs/acceptance.md；不能用按钮假冒真实执行/复核签署。

## 文件与ZIP导入

少量资料选择文件，多量资料粘贴目录路径。原始字节复制到sources/raw并登记SHA，ZIP原包保留，成员按内容来源关联；越界路径、软链接、加密或异常展开量会停止对应解包并说明。乱码尝试解码，仍有问题由Agent读内容识别，不要求用户自行整理命名。

文本、PDF等可生成来源ID对应的文字检索缓存；PDF无文字页需图像/OCR核查。docx、xlsx、pptx导入表示归档，Agent另用文档/表格/演示工具阅读。程序未实现RAR/7z解包；可使用已有解压软件将其解到单独资料目录再导入，保持原包，Agent登记关系。没有工具时再按当前授权处理下载。

## 从其它电脑运行

Python需3.10或更新。直接复制文件夹或Git克隆后，从本目录运行`python workbench.py serve`。本机特殊Python路径放runtime/python-path.txt，且不会上传Git；迁移后路径不可用时启动器自动尝试其它入口。Linux/macOS运行`sh 启动工作台.sh`。

新公司项目也自带workbench.py、companybench、skills和templates，可单独复制/运行。来源以相对路径和哈希绑定，迁移目录不会因盘符变化自动撤销事实；文件/口径/公式真变才影响对应绑定。

如PowerShell或终端本身启动失败，可用cmd或Anaconda Prompt，不把某个电脑的兼容问题变成所有人固定环境。端口由系统选空闲端口，不要求管理员或公网服务。

## Agent常用命令

```bash
python workbench.py --help
python workbench.py doctor
python workbench.py new --company "公司名称" --profile general
python workbench.py import --project "项目路径" --source "原资料目录"
python workbench.py index --project "项目路径"
python workbench.py candidate --project "项目路径" --file "Agent准备的候选.json"
python workbench.py validate --project "项目路径"
```

真实聊天/代理核准与报告命令详见[操作与报告参考](../skills/investment-company-analysis/references/operations-and-reporting.md)。本地库/CLI不是浏览器自动化身份证明；Agent应使用agent身份核准，不模拟用户窗口点击。

## Git

此工具包发布程序与方法，projects默认不进仓库。公司项目可明确执行：

```bash
python workbench.py git-init --project "公司项目路径"
python workbench.py git-save --project "公司项目路径" --message "整理原始资料并完成首轮分析"
python workbench.py git-status --project "公司项目路径"
```

本地提交不自动推送；请给Agent本次正确远程与发布范围。工具包和各公司项目各自Git，避免父目录/嵌套仓库混用；SSH私钥不进入项目。已有远程内容保留并核差异，不默认覆盖或强推。
