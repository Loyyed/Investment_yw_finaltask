# 研究交付 V2.0：下一家公司从一页简报开始

2026-10-25。通用框架从定题、证据、分解、解释、预测到复盘。新增skills/investment-research-delivery，接力已有证据链、商业模式、复现审计与研究预测技能，按需读取。

## 直接使用

网页首页选择公司后，点击“填写研究简报”。写问题与时点、客户与收费、关键变量、变化/矛盾、优先/替代解释、缺口和下一动作。支持浏览器草稿、下载中文简报、导入/导出同公司草稿。服务窗口采用沙箱，浏览器可能不允许本地持久化，此时下载备份；直接打开本地起步台可本地保存。

新公司：python workbench.py new --company 公司名称 --profile consumer

新建会同时生成outputs/研究起步台.html和work/research-brief-v2.md。已有普通公司项目：python workbench.py start --project 公司目录。start只重建起步台，已有简报保留；不改证据、核验、授权或签署。

独立公司项目包含方法与程序快照。已有外部快照不会被主工作台自动改写；需要升级时只迁移本轮明确方法/程序文件，保留其数据与历史。

## 报告表达与样式

companybench.delivery.enhance_atlas为含reader_v2的当前公司规格叠加白话导读、路线、术语、情景摘要与逐章提示。mindmap可创建带身份和跳转的SVG导图。insight的原数据、模型与validate_current保持职责，打开前仍按项目当前权威检查。新公司不附案例数字或参数。

每份合同写目的、动作、结论、疑问与下一步。正文先给判断，精确值、口径与原页可展开。一图回答一个问题，连线不代因果，缺失不填零。最终研究意见、参数与正式签署分别记录。

## 迁移原则

消费：量价、渠道与动销。工业：订单、交付与资本成熟。订阅：客户、留存和单客收入。金融：利差、信用与资本约束。只复制方法，当前公司的材料、证据ID、授权、姓名、机制和预测条件重新建立。

## 同源原数批次预览

网页研究总览提供“同源批次预览”，只列当前Unknown原披露。同一来源、期间、主体、单位、币种及报表范围合组，每批最多8项；元数据不足单列。下载可固化ID、原值、完整来源、当前binding与展示SHA。预览与导出不提交事实，真实答复到达后仍由原接口按展示binding处理明确覆盖项目，例外保留；输入变化先重展示。
